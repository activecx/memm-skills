# مهارات ميم لكلود كود وكوديكس

مهارات رسمية من ميم تُعين مساعدك الذكي على العمل كله، من فهم النشاط التجاري حتى تسليم إعلانات جاهزة بعد مراجعتها:

1. **البحث:** دراسة النشاط وعملائه ومنافسيه من موقعه ومن المصادر العامة.
2. **التخطيط:** خطة نمو أو حملة بتوصيات واضحة يمكن اختبارها.
3. **تنظيم العمل:** المراحل وتوزيع المهام والوقت والكريديت والمراجعات.
4. **أفكار الإعلانات:** أفكار مختلفة فعلًا، ولكل فكرة سبب ترشيحها وطريقة اختبارها.
5. **اختيار النماذج وضبط التكلفة:** أسعار محدّثة وموافقة واحدة على الميزانية.
6. **الإنتاج:** صور عامة وصور منتجات وإعلانات بالعربية وفيديو وتعليق صوتي وموسيقى ونماذج ثلاثية الأبعاد، كلها عبر ميم.
7. **مزامنة الشفاه:** صورة تتكلم أو تغني بتسجيلك الصوتي، ونقل الحركة من فيديو إلى صورة، وتعديل فيديو ترفعه بنفسك.
8. **المراجعة:** مطابقة كل نتيجة للمطلوب قبل اعتمادها.

لا تحتاج إلى تسمية المهارة؛ اطلب ما تريد بكلماتك، مثل «أريد إعلانًا لمنتجي»، وسيختار المساعد المهارة المناسبة.

## ما تحتاج إليه

- أحد البرنامجين التاليين، أو كلاهما:
  - Claude Code
  - Codex
- للإنشاء: أي باقة مدفوعة في ميم. أما مهارات البحث والتخطيط فتعمل من دون باقة.
- تثبيت المهارات مجاني، والإنشاء يستهلك الكريديت. ويعرض المساعد السعر دائمًا وينتظر موافقتك قبل أن يبدأ.

## الحصول على الحزمة

اختر إحدى الطريقتين:

1. نزّل الحزمة من موقع ميم، ثم فكّ ضغطها:

```
https://memm.ai/downloads/skills/memm-skills-2.0.0.zip
```

2. أو استنسخ المستودع العام بهذا الأمر:

```
git clone https://github.com/activecx/memm-skills.git
```

## التثبيت على ويندوز

افتح باورشيل داخل مجلد الحزمة، ثم شغّل هذا الأمر:

```powershell
powershell -ExecutionPolicy Bypass -File install\install.ps1
```

## التثبيت على ماك ولينكس

افتح الطرفية داخل مجلد الحزمة، ثم شغّل هذا الأمر:

```bash
bash install/install.sh
```

## تسجيل الدخول إلى ميم (مرة واحدة)

### Claude Code

اكتب هذا الأمر:

```
/mcp
```

ثم اختر من القائمة:

```
memm
```

ثم اختر:

```
Authenticate
```

### Codex

إن لم تُفتح نافذة تسجيل الدخول في المتصفح أثناء التثبيت، فشغّل هذا الأمر:

```
codex mcp login memm
```

## التحقق من الربط

افتح جلسة جديدة في برنامجك واكتب:

> تحقّق من ربط حسابي في ميم

تستخدم المهارة أداتين مجانيتين وتعرض باقتك ورصيدك، ولا يُخصم أي كريديت.

## الفحص والتحديث والإزالة

### فحص التثبيت من دون تغيير أي شيء

على ويندوز:

```powershell
powershell -ExecutionPolicy Bypass -File install\install.ps1 -Check
```

على ماك ولينكس:

```bash
bash install/install.sh --check
```

### التحديث

شغّل المثبّت مرة أخرى من أحدث حزمة. وإن كنت قد استنسخت المستودع، فحدّثه أولًا بهذا الأمر من داخل مجلده:

```
git pull
```

### الإزالة

على ويندوز:

```powershell
powershell -ExecutionPolicy Bypass -File install\install.ps1 -Uninstall
```

على ماك ولينكس:

```bash
bash install/install.sh --uninstall
```

لا تمسّ الإزالة مجلدات مشاريعك ولا حسابك في ميم ولا تصاميمك. ولا يضيف المثبّت الربط بميم إلا إذا لم يكن موجودًا، ولا يحذفه إلا إذا كان هو من أضافه.

## ما لا تفعله هذه المهارات

- النشر أو الجدولة على منصات التواصل.
- تشغيل الإعلانات أو شراؤها.
- قراءة نتائج الإعلانات.
- دبلجة فيديو موجود بخطوة واحدة.
- الاستماع إلى الصوت؛ لذلك يبقى التحقق من النطق وتوقيت مزامنة الشفاه عليك دائمًا.

تصرّح المهارات بذلك ولا تدّعي ما لا تستطيعه. ولا يمكنها كذلك أن تضمن النتائج، لكنّ كل نتيجة تُقارَن بموجزك، ويخبرك المساعد بما لم يتمكّن من التحقق منه.
